# Security policy

## Supported versions

Security fixes target the latest released version and the `main` branch.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/wayvz-io/external-dns-uddi-webhook/security/advisories/new)
to send the report to the maintainers.

Include the affected version, the conditions needed to reproduce the problem,
its likely impact, and any mitigation you have tested. Remove API keys, DNS
data, and other credentials from logs or examples before attaching them.
